Actualización a «Diseño especial a un tema dependiendo de si es Libre o Privado»

He hecho una pequeña modificación a la guía «Diseño especial a un tema dependiendo de si es Libre o Privado» que mejora un poco el rendimiento del código. Como ya bien sabéis los que lo hayáis implementado, el código funciona identificando las imágenes de los iconos con una cadena de texto. Desafortunadamente, por limitaciones de Foroactivo era necesario que la imagen fuese distinta para cada icono para poder identificarlos desde el código. Inicialmente el tutorial sugería que se utilizasen imágenes gifs 1x1 transparentes diferentes para cada icono y así obviar esta limitación. Teniendo así n imágenes distintas que descargar (aunque su peso fuese mínimo) y n peticiones http que realizar en los navegadores de vuestros usuarios. Con esta modificación se pasa de tener n peticiones y n imágenes distintas a tener tan solo una petición http y una imagen única para todos los iconos, lo cual es una mejora bastante interesante. Para lograrlo, añadimos una ancla a la URL que, al ser una imagen, no aporta ningún significado pero si que crea teóricamente URL únicas, aunque el recurso (la imagen) sea en realidad el mismo a ojos del navegador. Recomiendo a todos aquellos que hayan seguido la guía que hagan los cambios. No notarán una mejora sustancial, pero está ahí.
